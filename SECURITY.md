# Security Policy

## Reporting a Vulnerability
If you believe you have found a security vulnerability, please email: ovdttr@gmail.com

We request that you:
- Provide a description and minimal reproduction if possible
- Do not disclose publicly until we have assessed and addressed the issue

## Scope
- Python scripts under `Hyppopotamus/Scripts Demonstration`
- Coq sources under `Hyppopotamus/rocq-project`
- LaTeX sources under `Hyppopotamus/LATEX`

Artifacts, large datasets, and generated results are out of scope.
