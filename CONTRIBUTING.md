# Contributing (Private Repository)

This repository is private and intended for collaboration with invited researchers.

## Workflow
- Please open a branch for your changes and submit a pull request for review.
- Keep commits focused and descriptive.
- Do not commit large artifacts, datasets, generated plots, or build logs.

## Code style
- Python: prefer clear, readable code; avoid hard-coded paths; run with `python3`.
- Coq: ensure the project builds with `make` in `Hyppopotamus/rocq-project`.
- LaTeX: keep sources compilable; note that some files are pending review.

## Sensitive content
- Do not commit credentials, keys, or personal data.
- If in doubt, ask before sharing generated artifacts.
